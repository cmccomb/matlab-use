# matlab-use (archived prototype)

This repository is preserved as a historical experiment and is no longer
maintained. Use.m downloads MATLAB source from a URL, adds the downloaded
folder to the MATLAB path, and exposes discovered functions dynamically.
It does not pin a version or verify the downloaded content. Do not use it as
a dependency manager for reproducible or trusted work.

For maintained projects, install a reviewed release of each dependency and
record its version and source in your project. The code here remains
available for reference under its existing MIT license.
